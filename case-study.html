Fake News Detection.

A text-classification project that compares classic machine-learning models with a deep-learning model, and ships the result as an interactive web app.

PythonNLPTF-IDFStreamlit

The problem

News spreads faster than it can be checked. The goal of this project was to build a model that reads an article's text and flags whether it is likely to be fake, and to put that model in front of a non-technical user instead of leaving it in a notebook.

The approach

  1. Clean and vectorise the textArticles are preprocessed and converted to numeric features with TF-IDF, so each word is weighted by how informative it is across the dataset.
  2. Train and compare several modelsRather than picking one algorithm up front, four were trained on the same data and compared side by side.
  3. Deploy as an interactive appThe chosen pipeline, including the same TF-IDF preprocessing, is wrapped in a Streamlit app where anyone can paste text and get a prediction.
